Details:

1. **`rebuild_trial_plot_replicates` calls `->update` on `undef`** when a plot has no replicate stockprop. Before this PR `replace_stock` worked on such trials, so this is a regression for them. The upload flow has the same issue because it uses the same helper.

2. **Renames run in hash order and are checked one at a time.** With a valid template that has `repNumber` but no `plotNumber`, renumbering moves names between plots of the same accession. `replace_plot_name_fieldMap` then refuses a name that another plot in the set still holds. Whether that happens depends on Perl's hash order, so the same request sometimes works and sometimes fails. A two-pass rename (temporary names first) fixes it.

3. **Plain substring replacement in plot names.** `s/\Q$old\E/$new/` replaces the first match anywhere in the name, including inside the trial name or a longer accession name (`A1` in `A10`). #6353 limited the match to whole name parts (`(?:^|(?<=[-_]))\Q$old\E(?=[-_]|$)`), and its unit test covered these cases. Keeping that boundary still lets the test in this PR pass, including the "replace only the first occurrence" case.

4. **The layout is read from the cache without regenerating it first.** The trials that need this fix most are the ones where Replace Accession was used before, and their cache is stale (#4642). On a stale cache the swapped plots and the rep renumbering come from old data, while the SQL `UPDATE` changes the real rows. #6353 regenerated the cache before reading the layout. Adding that line back fixes S5.

5. The rep check in the new test (`[1, 2, 3]`) also passes without any rebuild, because the temporary accession takes over exactly the plots and reps of `test_accession3`. A swap into an accession that is already in the trial (S1) would actually exercise the renumbering.

A patch for 1–4 is ~50 lines in `FieldMap.pm` and `TrialMetadata.pm`: create the stockprop when it is missing, add a `rename_plots` helper with two passes, keep the whole-part match, and regenerate the cache before reading the layout. With it, all scenarios above pass, and so do `TrialMetadata.t` and `EditFieldMap.t` (130 tests). I can push it to this branch or open it as a separate PR, whichever you prefer.
